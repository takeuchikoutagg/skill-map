# 02. 機能要件

## 1. 機能一覧

| ID | 機能 | 概要 |
|---|---|---|
| F-01 | ボード表示 | 列とスキルを1画面に表示する |
| F-02 | スキル追加 | 列を指定してスキルを追加する |
| F-03 | スキル編集 | スキルの項目を編集する |
| F-04 | スキル削除 | スキルを削除する |
| F-05 | スキル移動 | ドラッグ&ドロップで、列間の移動と列内の並び替えをする |
| F-06 | 習得日の自動記録 | 習得済み列への移動で習得日を記録し、戻すと消す |
| F-07 | 列追加 | 新しい列を追加する |
| F-08 | 列名変更 | 列の名前を変更する |
| F-09 | 列の並び替え | 列の順番を入れ替える(任意。時間があれば実装) |

> **列の削除はできない。** 削除の機能は設けない(画面にも API にも用意しない)。

## 2. 機能の詳細

### F-01 ボード表示

- 画面を開いたとき、すべての列を左から並び順の昇順に表示する
- 各列に、その列のスキルを並び順の昇順に表示する
- 初回起動時は、デフォルトの3列(未習得 / 習得中 / 習得済み)が存在する(初期データとして投入)
- スキルがない列は、空の状態で表示する

### F-02 スキル追加

- 各列に「スキル追加」ボタンを置く(どの列にも直接追加できる)
- 追加時の入力項目: スキル名(必須)、ポイント・考察、優先度、期限
- 追加したスキルは、指定した列の末尾に置く
- 習得済み列に直接追加した場合も、習得日を記録する
- 初期値: 優先度は「中」、期限は空、ポイント・考察は空

### F-03 スキル編集

- カードから編集できる項目: スキル名、ポイント・考察、優先度、期限
- **習得日は編集できない**(画面に入力欄を出さず、API も受け付けない)
- スキル名を空にして保存することはできない

### F-04 スキル削除

- 各カードに削除ボタンを置く
- 誤操作を防ぐため、削除の前に確認ダイアログを出す
- 削除すると、同じ列のスキルの並び順を詰める

### F-05 スキル移動

- カードをドラッグ&ドロップして、別の列や、同じ列内の別の位置に移動できる
- 移動が成功したら、移動元と移動先の並び順を振り直す
- 画面は先に更新し(楽観的更新。保存の完了を待たずに画面へ反映する方式)、保存に失敗したら元の位置に戻してエラーを表示する

### F-06 習得日の自動記録

| 操作 | 習得日の扱い |
|---|---|
| 習得済み列以外 → 習得済み列へ移動 | 移動した日(サーバー側の日付)を記録する |
| 習得済み列 → 習得済み列以外へ移動 | 消す(空に戻す) |
| 習得済み列内での並び替え | 変更しない |
| 習得済み列以外の列どうしの移動 | 変更しない(空のまま) |
| 習得済み列に直接追加 | 追加した日を記録する |

- 記録するのは、サーバーが決めた日付のみ。クライアントが送る値は使わない
- 習得日はカードに表示する(値が入るのは、習得済み列にあるスキルだけ)

### F-07 列追加

- ボードの右端に「列を追加」を置く
- 入力項目: 列名(必須)
- 追加した列は、一番右に置く
- 追加した列は通常の列として扱う(習得日は記録しない)
- 追加した列は削除できないため、作りすぎないよう画面の説明文に注意書きを添える(名前の変更で使い回せる)

### F-08 列名変更

- 列名を編集できる(習得済み列も名前は変更できる)
- 空の名前は保存できない

### F-09 列の並び替え(任意)

- 列をドラッグして、順番を入れ替えられる
- 第1段階の必須要件には含めない

## 3. データ要件

詳細は [05-ER図.md](05-ER図.md) を参照。

| 対象 | 項目 | 制約 |
|---|---|---|
| 列 | 列名 | 必須、50文字以内 |
| 列 | 習得済みフラグ | 習得済み列は全体で1つだけ |
| スキル | スキル名 | 必須、100文字以内 |
| スキル | ポイント・考察 | 任意、5,000文字以内 |
| スキル | 優先度 | 高 / 中 / 低のいずれか |
| スキル | 期限 | 任意、日付 |
| スキル | 習得日 | 自動記録のみ、日付 |

## 4. 非機能要件

| 項目 | 要件 |
|---|---|
| 操作性 | 画面遷移なしの1画面で、すべての操作が完結する |
| 性能 | スキルが数百件あっても、操作が引っかからない(ボード全体を1回の API で取得する) |
| データ保持 | 再読み込みしても、列・スキル・並び順・習得日が保持される |
| 整合性 | 移動時の並び順の更新と習得日の更新は、1つのトランザクション(まとめて成功か失敗かを決める処理単位)で行う |
| 対応ブラウザ | 最新版の Chrome、Safari、Edge(デスクトップ) |
| セキュリティ | SQL インジェクションと XSS への対策(Rails と React の標準機能を使う)。CORS は許可するオリジンを限定する |
| コスト | AWS の無料利用枠内。詳細は [06-技術スタック.md](06-技術スタック.md) |
| テスト | API のテスト(RSpec)で、F-05 と F-06 のルールを検証する |

## 5. API 一覧(概要)

すべて `/api/v1` 配下。列を削除する API は設けない。

| メソッド | パス | 機能 |
|---|---|---|
| GET | /lists | F-01 ボード全体の取得 |
| POST | /lists | F-07 列追加 |
| PATCH | /lists/:id | F-08 列名変更 |
| POST | /lists/:list_id/skills | F-02 スキル追加 |
| PATCH | /skills/:id | F-03 スキル編集 |
| DELETE | /skills/:id | F-04 スキル削除 |
| PATCH | /skills/:id/move | F-05、F-06 スキル移動 |
